# Audio focus coordination
Observe Android AudioFocusRequest.Builder and public request/abandon methods, including legacy music stream. Observe actual registered native listener on loss/gain, preserve native callbacks. No hidden Android API or phone permission. Supplement focus only while confirmed foreground engine plays and no native focus request was observed; no automatic background reacquisition. Request speech content and pause-on-duck. Android 15+ can deny focus without top app/FGS; denied requests logged. System call mode listener API31+; ring/in-call/in-communication. No claim of detecting other apps that don't request focus or system ducking of unmodified native requests. Default focus/call pause on, auto-resume off. Optional transient resume only same engine/video/generation; permanent loss requires explicit user action. Cancel all module-owned background and mini recovery on interruption, allow native pause, do not touch native listener behavior. Native foreground automatic play after focus gain may still occur; actual devices require verification. Main remains unchanged.
